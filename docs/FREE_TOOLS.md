# Free Tools

MyEmailVerifier offers several free tools to help you verify emails and validate domains without requiring code.

## 🎯 Available Free Tools

### 1. Single Email Verifier

**What it does:** Verify a single email address instantly.

**How to use:**
1. Visit [MyEmailVerifier.com](https://myemailverifier.com)
2. Enter an email address
3. Click "Verify"
4. See instant results

**What you get:**
- Email validation status
- Domain information
- Catch-all detection
- Deliverability score

**Limit:** 5 verifications/day (Free plan)

---

### 2. Bulk Email List Verifier

**What it does:** Upload and verify multiple emails at once.

**How to use:**
1. Go to Dashboard → Bulk Verifier
2. Upload CSV or paste email list
3. Click "Verify All"
4. Download results

**Supported formats:**
- CSV (.csv)
- Plain text (.txt)
- Copy/paste list

**Limit:** 100 emails per upload (Free plan)

---

### 3. Domain Validator

**What it does:** Check domain validity and MX records.

**How to use:**
1. Go to Tools → Domain Validator
2. Enter domain name (e.g., google.com)
3. View MX records and domain status

**Information provided:**
- Domain validity
- MX record list
- Catch-all detection
- DNS records

**Limit:** 10 domains/day (Free plan)

---

### 4. Catch-all Detector

**What it does:** Detect if a domain uses catch-all email handling.

**How to use:**
1. Navigate to Tools → Catch-all Detector
2. Enter domain
3. Get instant result

**Returns:**
- Catch-all status
- Domain validity
- Evidence of catch-all behavior

**Limit:** 10 checks/day (Free plan)

---

### 5. Email List Duplicate Remover

**What it does:** Remove duplicate emails from a list.

**How to use:**
1. Go to Tools → Duplicate Remover
2. Paste or upload email list
3. Click "Remove Duplicates"
4. Download cleaned list

**Features:**
- Case-insensitive duplicate detection
- Preserves original order
- Shows statistics

**Limit:** 1000 emails (Free plan)

---

### 6. Email Format Validator

**What it does:** Check if email format is valid.

**How to use:**
1. Navigate to Tools → Format Validator
2. Enter email address
3. Get instant format validation

**Validates:**
- Email syntax
- Domain format
- Special characters
- Length validation

**Limit:** Unlimited

---

### 7. Domain Whois Lookup

**What it does:** Get domain registration information.

**How to use:**
1. Go to Tools → Whois Lookup
2. Enter domain name
3. View registration details

**Information:**
- Registrant info
- Registration date
- Expiry date
- Registrar details

**Limit:** 10 lookups/day (Free plan)

---

### 8. Email Account Validator

**What it does:** Check if an email account exists without verification.

**How to use:**
1. Tools → Account Validator
2. Enter email address
3. Get existence status

**Returns:**
- Account existence (probable)
- Response from mail server
- Domain status

**Limit:** 20 checks/day (Free plan)
